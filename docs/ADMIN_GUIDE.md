# Admin & Audit Panel Guide — JeevanCare

This guide describes the administrative and audit controls available to platform administrators.

---

## 1. Accessing the Admin Panel

- Accounts with the `admin` role can navigate to the **Admin Audit Panel** via the settings or header menu.
- Non-admin users are strictly blocked from loading administrative controls.

---

## 2. Administrative Capabilities

### 2.1 Audit Log Inspection
- Review platform authentication events and role transitions.
- Monitor access timestamps and query metadata for security auditing.

### 2.2 System Health & Metrics
- Monitor server liveness, API latency benchmarks, and active user metrics.

### 2.3 User & Role Management
- Review user profile role assignments (`patient`, `doctor`, `admin`).
- Verify doctor registration credentials and profile statuses.
